# Quick start

Requires **scarb ≥ 2.20** (ships `scarb execute`, `scarb prove`, `scarb verify`).

## 1. Validate the bigint math

```sh
cd cairo/lib
scarb test
# 2 passed, 1 ignored — the full verify exceeds cairo-test's 2^32 gas cap
```

The two passing tests exercise both limb domains: `x^2 mod N` (N domain) and
`2^T mod L` (L domain). The full Wesolowski check needs more gas than
cairo-test allows, so it runs via the executable instead:

## 2. Run the full verification as an executable (gas off)

```sh
cd ../exec
python3 ../../scripts/write_exec_512.py   # writes vectors/exec_args_512.json
scarb execute --arguments-file ../../vectors/exec_args_512.json --print-program-output
# Program output: 1   <- proof verifies
```

This runs the ~billion-step computation with gas disabled — the same path the
prover will consume.

## 3. Prove the execution (big machine)

```sh
scarb execute --output=standard --arguments-file ../../vectors/exec_args_512.json
scarb prove --execution-id 1
# -> target/execute/vdf_exec/execution1/proof/proof.json
scarb verify target/execute/vdf_exec/execution1/proof/proof.json
```

> **Memory**: the 512-bit prover input is ~140MB and Stwo needs ~10-17GB RAM to
> prove it. The 1024-bit trace is ~4x heavier. Use a 16GB+ machine; the
> execution artifacts are portable — copy the execution dir and prove there.

## Modulus sizes

`N_LIMBS` in `cairo/lib/src/lib.cairo` selects the domain:

| N_LIMBS | Modulus | Use |
|---|---|---|
| 8 | 512-bit | demo / CI / small boxes |
| 16 | 1024-bit | production baseline |
| 32 | 2048-bit | production, serious proving machine |
