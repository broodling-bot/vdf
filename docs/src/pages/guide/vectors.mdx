# Reproducing vectors

Everything is generated from the Python reference — no hand-written constants.

## Generate vectors

```sh
python3 ref/vdf_reference.py [output.json]
```

Writes an array of vectors, each containing: `N`, `x`, `y`, `π`, `L`, `r`
(as limb arrays), `T`, and the RSA parameters. The reference asserts the RSW
φ(N) shortcut equals sequential squaring, and that the Wesolowski proof
verifies, before emitting.

## Regenerate Cairo tests

```sh
python3 scripts/regen_clean_tests.py
```

Writes `cairo/lib/src/tests.cairo` — two gas-cheap passing tests (both limb
domains) plus the full-verify test marked `#[ignore]` (exceeds cairo-test's
2^32 gas cap; run it via `scarb execute` instead).

## Regenerate executable arguments

```sh
python3 scripts/write_exec_512.py
```

Writes `vectors/exec_args_512.json` — the flat felt252 input array for
`scarb execute`, with the leading Span-length felt.

## Validate model changes first

`ref/cairo_model_v2.py` is the exact Python mirror of the Cairo algorithm.
If you change the Cairo math:

1. Change `cairo_model_v2.py` first.
2. Run it against the vectors: `python3 ref/cairo_model_v2.py vectors/vdf_vectors_512.json`.
3. Diff-test random inputs against the old model before porting.
4. Port limb-for-limb, then run `scarb execute` on the smallest vector.
